# M3 Muscarinic Receptor Antagonist ML Pipeline

Machine learning pipeline for predicting M3 muscarinic receptor antagonist
activity using scaffold-stratified cross-validation and Morgan fingerprints.

## Project structure

    data/        Raw, processed, and external datasets
    notebooks/   Jupyter notebooks
    src/         Reusable source modules
    models/      Saved model artefacts
    results/     Tables and figures
    scripts/     Standalone runnable scripts

## Setup

    conda env create -f environment.yml
    conda activate m3_ml

## Data

Input: ChEMBL_M3_consensus_labels_more_negatives_with_meta.csv
Labels: active / active_single / inactive / inactive_single
        (consensus from ChEMBL + BindingDB)

## Key notebook

notebooks/M3_ML_classic_20260225.ipynb
  Scaffold-stratified 10-fold CV, Morgan FP + PhysChem,
  Logistic Regression, domain shift quantification, UMAP projection.

## Reproducibility

1. create environment
conda env create -f environment.yml

2. activate
conda activate m3_ml

3. train model
python scripts/train_model.py

4. generate figures
python scripts/generate_figures.py

## Revision update (2026-07)

Following peer review, the analysis was substantially extended:

- **New validation analyses** (`scripts/09_additional_analyses.py`): random-split
  baseline, Tanimoto similarity between test and development sets, applicability-
  domain-restricted held-out performance, and a sensitivity ablation excluding
  single-measurement compounds.
- **Corrected `04_y_randomization.py`**: now uses the identical scaffold-
  stratified CV protocol as `02_train_model.py` (previously used a
  non-matching `GroupKFold`/balanced-class-weight setup that understated the
  real-model reference AUC).
- **Six supplementary figures** added (`results/figures/figure_s2` through
  `figure_s6`, plus the corrected Y-randomization histogram), generated by
  `scripts/08_umap_split_comparison.py` and
  `scripts/10_generate_supplementary_figures.py`.
- `environment.yml` now pins exact versions (scikit-learn 1.7.1, rdkit
  2026.3.1, umap-learn 0.5.11) used to verify all reported numbers.
- See `scripts/README.md` for the full pipeline order and outputs.
