# 1. Project Objective

The goal of this project is to develop a robust ligand-based machine learning classifier
capable of identifying antagonists of the human M3 muscarinic acetylcholine receptor
(CHRM3).

Key requirements:

- avoid scaffold leakage
- ensure realistic generalisation to unseen chemotypes
- maintain model interpretability
- provide full computational reproducibility

# 3. Molecular Representation

Molecules were represented using:

**Morgan fingerprints (ECFP4)**

Parameters:

```
radius = 2
nBits = 2048
useChirality = True
```

Optional additional features:

- physicochemical descriptors: MolWt, MolLogP, NumHDonors, NumHAcceptors, TPSA,
  NumRotatableBonds (concatenated without scaling)

Fingerprint generation implemented using **RDKit**.

---

# 4. Machine Learning Model

Classifier:

```
Logistic Regression
```

Pipeline:

```
MorganFP + PhysChem → LogisticRegression(solver=liblinear, class_weight=None)
```

No StandardScaler is applied: Morgan fingerprint bits are binary and uniformly bounded;
logistic regression with liblinear is robust to the moderate scale difference introduced
by the six physicochemical descriptors in this setting.

No class_weight parameter is used. Class-balance correction is deliberately omitted to
preserve calibrated probability outputs. Label reliability is handled separately via
confidence-based sample weights passed at fit time:

| Label            | Sample weight |
|------------------|---------------|
| active           | 1.0           |
| inactive         | 1.0           |
| active_single    | 0.5           |
| inactive_single  | 0.7           |

Key properties:

- confidence-based sample weighting (not class-balance weighting)
- L2 regularisation (C = 1.0)
- probabilistic outputs (predict_proba)

Model bundle:

```
models/m3_fp_physchem_scaffoldcv.joblib
```

# 5. Validation Strategy

The model was evaluated using **scaffold-grouped cross-validation**.

Grouping:

```
Bemis–Murcko scaffolds
```

Cross-validation scheme:

```
Outer split:  StratifiedGroupKFold(n_splits=5)  → dev (n=1813) / held-out test (n=455)
Inner CV:     StratifiedGroupKFold(n_splits=10) → 10-fold scaffold-stratified OOF
```

This prevents structurally related analogues from appearing in both training and test
folds. The held-out test set is never used for training or threshold selection.

OOF threshold selection: grid search over 181 thresholds in [0.05, 0.95], maximising MCC
on pooled OOF predictions. Selected threshold: **0.70**.

References:

- Bemis & Murcko 1996
- Sheridan 2013
- Wallach 2018

# 6. Model Performance

Out-of-fold metrics (FP + PhysChem, threshold = 0.70, n = 1813):

| Metric            | Value |
|-------------------|-------|
| ROC-AUC           | 0.983 |
| PR-AUC            | 0.995 |
| MCC               | 0.860 |
| Balanced Accuracy | 0.946 |
| Brier score       | 0.038 |

Held-out scaffold-stratified test set (n = 455, prevalence = 0.789):

| Metric            | Value |
|-------------------|-------|
| ROC-AUC           | 0.971 |
| PR-AUC            | 0.993 |
| MCC               | 0.750 |
| Balanced Accuracy | 0.897 |

The decrease in MCC relative to OOF (0.750 vs 0.860) reflects true scaffold
generalisation difficulty and partial threshold transfer loss across the outer fold
boundary.

# 7. Error Analysis

Error analysis included:

- per-scaffold OOF performance (MCC, balanced accuracy, error count)
- identification of **hard scaffolds** (n >= 10 OOF compounds, MCC < 0.5)
- Tanimoto similarity analysis for hard scaffolds (domain shift quantification)
- UMAP visualisation of chemical space

Three hard scaffolds were identified. Two have MCC = 0 due to extreme within-scaffold
class imbalance (1–2 inactives in 17–29 compounds), making MCC numerically unstable
rather than indicating systematic model failure. The third scaffold (n = 18, 10/18 errors,
MCC = 0.193) represents a genuinely difficult mixed-activity series.

```
scripts/generate_figures.py
```

# 8. Applicability Domain

Prediction reliability depends on chemical similarity to training data.

Proxy metric:

```
Maximum Tanimoto similarity to training compounds (Morgan fingerprints)
```

However:

- high similarity **does not guarantee correct prediction**
- scaffold-level errors remain possible even within the training distribution

The hard-scaffold analysis shows that two of the three hard scaffolds have mean maximum
Tanimoto similarity > 0.70 to the rest of the dataset yet are systematically
misclassified. Per-scaffold OOF error rates should therefore be consulted alongside
similarity metrics when assessing prediction confidence.

Applicability domain analysis discussed in §4.5 of the manuscript.

# 9. Model Interpretability

Feature importance analysis was performed by ranking Morgan fingerprint bits by logistic
regression coefficient magnitude.

Script:

```
scripts/morgan_feature_importance.py
```

Outputs:

```
results/tables/top_morgan_bits.csv
results/figures/fig_feature_importance_morgan_bits.png
```

Each fingerprint bit corresponds to a specific atom environment at ECFP4 radius 2,
visualised by highlighting the activating environment in the parent molecule using
`Draw.MolToImage(highlightAtoms=..., highlightBonds=...)`. Coefficients should be
interpreted as marginal contributions in the regularised model, not as independent
measures of fragment activity.

# 15. Conclusion

The scaffold-aware machine learning pipeline developed here provides a robust and
interpretable method for identifying M3 muscarinic receptor antagonists while avoiding
common pitfalls of ligand-based benchmarks such as scaffold leakage and memorisation.

Key design decisions — scaffold-stratified outer/inner splits, OOF threshold selection,
confidence-based sample weights without class-balance correction, and per-scaffold error
profiling — ensure that reported metrics reflect genuine generalisation to unseen scaffold
families rather than interpolation within seen chemotypes.

The repository contains all code required to reproduce the complete analysis from the
raw input CSV to the final manuscript figures.
